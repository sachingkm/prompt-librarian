# Project conventions

## Punctuation

Use ASCII-only punctuation in all source code and documentation. No em-dashes, smart quotes, or ellipsis characters.

- Em-dash and en-dash: use ASCII hyphen `-`
- Smart double quotes and smart single quotes: use straight `"` and `'`
- Ellipsis: use three dots `...`

This applies to:

- All files under `app/` (TypeScript, TSX, CSS, HTML, JSON, config)
- `README.md` and any other Markdown documentation
- Commit messages
- Code comments

The `Design/` directory is reference material from the design phase and is exempt.
